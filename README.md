# Blind People App – React Native

## 📱 About the Project

The **Blind People App** is a mobile application developed using **React Native** to assist visually impaired people in their daily activities. The application uses technologies such as **voice assistance, computer vision, barcode scanning, and navigation** to provide useful information and improve independence and accessibility.

## 🎯 Objectives

* Assist visually impaired users in their daily activities.
* Provide information through voice-based interaction.
* Identify objects and provide descriptions using vision capabilities.
* Scan and recognize barcodes.
* Provide navigation and direction assistance.
* Create an accessible and user-friendly mobile application.

## ✨ Features

* 🗣️ **Voice Assistance** – Interact with the application using voice.
* 👁️ **Vision Assistance** – Analyze images and provide useful information.
* 📷 **Object Recognition** – Help users understand their surroundings.
* 🔍 **Barcode Scanner** – Scan and identify product barcodes.
* 🗺️ **Navigation & Directions** – Provide directions and location assistance.
* 🔐 **Authentication** – User sign-in and authentication functionality.
* 📱 **Mobile Application** – Built for a smooth and accessible mobile experience.

## 🛠️ Technologies Used

* React Native
* Expo
* TypeScript
* JavaScript
* Expo Router
* REST APIs
* Voice/Speech API

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the Project

```bash
cd Blind-People-Aap-react-native-
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
npx expo start
```

You can then run the application using an Android emulator, iOS simulator, or a compatible mobile device.

## 🔑 API Configuration

Before running the application, configure the required API keys and environment variables according to the project requirements.
